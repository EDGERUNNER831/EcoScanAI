ECOSCAN AI — АВТОМАТИЧЕСКОЕ РАСПОЗНАВАНИЕ (ПРОТОТИП)

1. Распакуйте архив.
2. Откройте папку в VS Code.
3. Установите расширение Live Server и нажмите Go Live в index.html.
4. Дождитесь сообщения «AI готов». Нужен интернет.
5. Загрузите фото одного предмета и нажмите «Определить материал».
6. Если ответ ошибочен, вручную исправьте категорию.
7. Для GitHub Pages загрузите index.html, style.css, script.js в корень репозитория.

РЕАЛЬНАЯ МОДЕЛЬ: https://github.com/AetherCore4/SmartWaste-AI
Файлы модели подгружаются через jsDelivr (не включены в ZIP).
Поддерживает автоматическую классификацию только Plastic, Paper, Metal.
Glass и Other доступны только для ручной коррекции.
Модель может ошибаться, особенно на сложных фотографиях.
Нейросеть и CDN не были протестированы в живом браузере в среде сборки.
Для защиты хакатона проверьте доступность CDN и протестируйте фото заранее.
Бесплатный статический сайт; банковская карта и платный API не нужны.
